# DDX Offline QR

> DDX is a Russian app for gym, hence I Russian is used here in README

Оказывается, что QR-код в DDX это просто строка вида
`DDX_[user id]_[static number]_[base32 Unix time]` (спасибо Deimos). Я запилил
приложение для себя, чтобы не пользоваться их блевотным приложением, куда ещё
нужно логиниться.

Если вам надо, пользуйтесь тоже.
